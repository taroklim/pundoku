# PD-163 — где живут режимы на экране Play

Макет: `design/pd163-modes-layout.html` (самодостаточный; на десктопе — рамка iPhone + панель
переключателей, на телефоне — во весь экран, панель по кнопке «Mockup controls» сверху).
Кадры: `node design/pd163-shots.mjs` (из `products/pundoku`) → `design/pd163-shots/`.
**Это только размещение.** Механики не проектировались; у каждого режима — описание в 1–2
предложения (en/uk/ru, §6). Код продукта не менялся.

Вход: `products/pundoku/CLAUDE.md`, `reports/sudoku-pwa-research/07-concept-draft.md` (релиз 2,
визуал v2), `design/pd144-play-c.html/.md` (утверждённый хаб C), код `apps/web/src/play/PlaySetup.tsx`,

`modality`, `onboarding`, `lists-and-tables`, `collections`, `tab-bars`).

## 1. Одним абзацем

Шесть входов: **Классика, Чернила, Лжец, Мелодия, Фонарь, Глифы** (Фонарь/Глифы — два режима
«Восприятия»). **Питомец-клякса — не режим, а опция:** на поле он не выходит никогда, значит выбирать
его перед партией бессмысленно; это переключатель в Настройках → «Дополнительно». Рекомендую
**вариант C — модель владельца, нарисованная списком**: на Play под «Продолжить» одна карточка
«Режимы», строка на режим (значок, имя, описание одной-двумя строками). Тап по строке: есть
незавершённая игра этого режима — она открывается сразу; нет — снизу выезжает шит «описание +
сложность + Начать». Незавершённая игра заменяет описание в строке на «Не закончена · Сложно ·
осталось 47 · 03:18», поэтому «Продолжить» держит только игру дня (она живёт на Today). В шапке
партии режим — чип со значком и словом (обобщённый чип «Чернила»), Классика без чипа.

## 2. Решения, общие для всех вариантов

| # | Решение | Почему | Пересматривать? |
|---|---|---|---|
| 1 | **Слот сохранения на каждый режим** (обобщение двух слотов PD-144): день + по одной незавершённой игре на режим | Иначе «тап → открывает незавершённую игру этого режима» (модель владельца) невозможна; и это то же правило «ни одна игра не уничтожает другую», утверждённое в PD-144 | нет |
| 2 | **Питомец — опция в Настройках → «Дополнительно»**, переключатель + описание + превью карточки; по умолчанию **выкл.** | Концепт: «только карточка/Year, никогда на поле», «необязательный». Режим выбирают для партии — питомец к партии не относится. Отдельная кнопка режима обещала бы то, чего на поле не будет (`writing.md`, правило PD-144 «не обещать несуществующее») | да — значение по умолчанию (выкл./вкл.) решает владелец |
| 3 | **Мелодия — режим** (как в списке владельца) | Так задано в тикете. Но по сути это слой звука над любой сеткой; если владелец захочет «Лжец с мелодией», Мелодия переезжает переключателем в «Дополнительно» рядом с питомцем — раскладка это выдерживает без переделки | **да, спорно** |
| 4 | Режимы **взаимоисключающие** (один на партию) | Один чип в шапке, один слот на режим, одна строка «Продолжить». Комбинации — механика, не размещение | да, когда дойдёт до механик |
| 5 | Порядок режимов **фиксированный** (Классика, Чернила, Лжец, Мелодия, Фонарь, Глифы), не по недавности | Пространственная память: строка не прыгает от того, что в ней появилась незавершённая игра (`design-principles.md › Consistency`). Новые режимы встают **в конец** | нет (типовое) |
| 6 | **Описание режима живёт в шите выбора сложности** — показывается при каждом входе, над списком сложностей; в C — ещё и в самой строке | На iPhone нет наведения, «тултип» = текст, который видно без жеста. Правило читается до первого хода (концепт v2 п. 7: режим «только когда игрок видит правило до первого хода») — шит стоит ровно между тапом и началом партии | нет |
| 7 | **Подсказка по долгому нажатию** (A, C): контекстное меню, **заголовок меню = описание режима**, пункты «Продолжить» (если есть игра) и «Новая сетка…» | Системный паттерн iOS (у контекстного меню есть слот заголовка); ускоритель, а не единственный путь — описание и так есть в шите | да (необязательный слой) |
| 8 | Пометка **«Новое»** на режимах, в которые ни разу не заходили; исчезает после первого входа | Обнаруживаемость без онбординга и без поп-апов при запуске (`onboarding.md`: «Teach through interactivity»). Не бейдж-счётчик и не награда — просто ярлык | да — можно убрать, если покажется шумом |
| 9 | Шапка партии: **чип режима (значок + слово)** в подшапке, как сейчас у Чернил; Классика — без чипа. При AX3/узком экране чип схлопывается до значка (слово остаётся a11y-именем) — это уже реализовано для Чернил (D-2) | Решение владельца по Ink (PD-144 №7) — обобщаем, а не придумываем новое; заголовок «Play/Гра/Игра» не меняется, иначе разъедется выравнивание шапок трёх вкладок | нет |
| 10 | **Первый старт Чернил** — одноразовый шит правила PD-74 остаётся; показывается **после** закрытия шита режима, не поверх | `sheets.md`: «Display only one sheet at a time… close the first sheet before displaying the new one». Правило Ink длиннее 2 предложений, в описание не помещается | да — можно слить PD-74 в шит режима |
| 11 | Ни цвета, ни токена нового. Все значки режимов — контур 1.7, цвет «чернила»; Лжец тоже чернилами (сургуч зарезервирован за ошибкой/обвинением) | Токены v2 и PD-144 | нет |

## 3. Варианты

Переключатель **Variant** в панели макета. Во всех трёх — одни и те же шит режима, шапка партии и
экран питомца; разница только в хабе и в поведении «Новая сетка» из меню «⋯».

### A — вариант владельца: кнопка (плитка) на каждый режим

```
┌ Play                                 ⚙ ┐
│ ПРОДОЛЖИТЬ                              │
│ ┌─────────────────────────────────────┐ │
│ │ ▦ Головоломка дня                 › │ │  → вкладка Today (как в PD-144)
│ │   Средне · осталось 28 · 12:04      │ │
│ └─────────────────────────────────────┘ │
│ РЕЖИМЫ                                  │
│ ┌────────────────┐ ┌────────────────┐   │
│ │ ▦              │ │ ✒              │   │
│ │ Классика       │ │ Чернила        │   │
│ └────────────────┘ └────────────────┘   │
│ ┌────────────────┐ ┌────────────────┐   │
│ │ ☺        Новое │ │ ♪        Новое │   │
│ │ Лжец           │ │ Мелодия        │   │
│ │ ● Сложно · ос… │ │                │   │  незавершённая — строкой статуса в плитке
│ └────────────────┘ └────────────────┘   │
│ (Фонарь, Глифы)                         │
│ Свои игры не попадают в ваш год.        │
└ [Today]      [Play]      [Year] ────────┘
```

- **Тап:** незавершённая игра режима → сразу доска; нет → шит «описание + сложность + Начать».
- **«Продолжить» при нескольких незавершённых:** в секции **только день**. Каждая игра режима живёт
  на своей плитке (точка + «Сложно · осталось 47 · 03:18»). Вторая дверь в ту же игру не нужна.
- **Новая игра в режиме, где уже есть незавершённая** (дыра в исходной формулировке: тап всегда
  продолжает, начать новую нельзя): «⋯ → Новая сетка» в партии открывает **шит этого же режима** с
  предупреждением «Незаконченная сетка (…) будет отброшена» и кнопкой «Начать новую»; плюс долгое
  нажатие на плитку → «Новая сетка…». Решение PD-144 «Новая сетка → хаб» здесь меняется: иначе хаб
  вернёт в ту же партию.
- **Сильное:** все режимы равноправны и видны сразу; 1 тап до продолжения.
- **Слабое:** описание в плитку не помещается — до шита режим представлен только именем и значком;
  2 колонки на 320 pt дают плитку ~139 pt, на AX3 сетка всё равно превращается в 1 колонку (то есть в
  список, только выше); 7-й режим оставляет «сироту» в последнем ряду; плитки — новый для приложения
  компонент (всё остальное — сгруппированные списки).

### B — наш: Классика как основной вход + «Другие режимы» списком

```
│ ПРОДОЛЖИТЬ                              │
│  ▦ Головоломка дня        …           › │
│  ▦ Классика   Средне · ос. 31 · 08:40 › │  каждая незавершённая — своей строкой
│  ✒ Чернила    Сложно · ос. 47 · 03:18 › │
│  ☺ Лжец       Эксперт · ос. 52 · 01:05› │
│ НОВАЯ СЕТКА · КЛАССИКА                  │
│  Легко   38 открытых · одиночки         │
│  Средне  30 открытых · одиночки       ✓ │
│  … (5 строк)                            │
│ ДРУГИЕ РЕЖИМЫ                           │
│  ✒ Чернила  Каждая цифра окончательна…› │
│  ☺ Лжец     Одна из данных цифр лжёт… › │  → шит режима
│  …                                      │
├─────────────────────────────────────────┤
│              [ Начать ]                 │  закреплена (Классика)
```

- Ближе всего к утверждённому хабу PD-144: строка «Режим» превращается в раздел.
- **«Продолжить»:** все незавершённые, одна строка на слот (значок + имя режима), порядок фиксированный.
  Строки режимов ниже **всегда** открывают шит (новая игра); при незавершённой — с предупреждением.
- **Слабое:** самый длинный хаб (на 390 при обычном тексте уже прокручивается); закреплённая
  «Начать» относится только к Классике, а видна и тогда, когда палец над «Другими режимами» — две
  разные кнопки старта на одном экране; Классика и остальные режимы стартуют разными путями.
  Режимы — «второй сорт», что противоречит намерению владельца сделать их равноправными кнопками.

### C — наш, **рекомендую**: модель владельца, но списком

```
│ ПРОДОЛЖИТЬ                              │
│  ▦ Головоломка дня                    › │  → Today
│ РЕЖИМЫ                                  │
│ ┌─────────────────────────────────────┐ │
│ │ ▦ Классика                        › │ │
│ │   Обычное судоку: заметки, отмена…  │ │
│ │ ✒ Чернила                         › │ │
│ │   Каждая цифра окончательна: без…   │ │
│ │ ☺ Лжец                            › │ │
│ │   ● Не закончена · Сложно · ос. 47  │ │  статус вместо описания, цветом чернил
│ │ ♪ Мелодия  [Новое]                › │ │
│ │   Каждая поставленная цифра звучит… │ │
│ │ (Фонарь, Глифы)                     │ │
│ └─────────────────────────────────────┘ │
│ Свои игры не попадают в ваш год.        │
```

- Поведение — **ровно вариант владельца** (тап → продолжение или шит; «⋯ → Новая сетка» → шит
  этого режима; долгое нажатие → меню с описанием).
- **«Продолжить»:** только день; игры режимов — статусом в своих строках.
- Закреплённой «Начать» на хабе **нет** ни в A, ни в C: «Начать» живёт в шите, внизу, в зоне
  большого пальца, и всегда относится к одному, только что выбранному режиму.

### Сравнение

| | A плитки | B Классика + список | C список |
|---|---|---|---|
| Тапов до продолжения игры режима | 1 | 1 (из «Продолжить») | 1 |
| Тапов до новой игры (режим без игры) | 2–3 (режим → [сложность] → Начать) | Классика 1–2; прочие 2–3 | 2–3 |
| Описание видно до тапа | нет (только шит/долгое нажатие) | да, у «других» | **да, у всех** |
| Где незавершённые игры | в плитках | в «Продолжить» | в строках |
| Рост до 7–10 режимов | сирота в ряду, хаб растёт по 2 | список растёт на строку | **список растёт на строку** |
| AX3, 320 pt | 1 колонка = высокий список | самый длинный хаб | естественно: строка переносится |
| Новый компонент | плитка | нет | нет (строка хаба PD-144) |
| Отличие от утверждённого PD-144 | хаб переписан | минимальное | хаб переписан |

## 4. Рекомендация: C

1. **Список, а не плитки, — потому что у режима есть текст, который надо прочитать до выбора.**
   `lists-and-tables.md`: «Prefer displaying text in a list or table… the row-based format is
   especially well suited to making text easy to scan and read». Плитке есть смысл, когда главное —
   картинка (`collections.md`), у нас главное — правило. На AX3 и на 320 pt плитки всё равно
   складываются в одну колонку, то есть в список — только без описания.
2. **Поведение владельца сохранено целиком.** Тап по режиму — либо продолжение, либо шит
   «описание + сложность + Начать». Шит — короткая модальная задача с одной целью
   (`modality.md`: «Aim to keep modal tasks simple, short, and streamlined»; «Make it easy to identify
   a modal view’s task» — заголовок шита = имя режима со значком), «Отмена» в паре с «Начать»
   (`sheets.md`: «Provide an alternative to the Done button»).
3. **Не сегмент.** Сегмент «Классика | Чернила | Лжец | …» напрашивается, но HIG ограничивает его
   ~5 сегментами на iPhone (`segmented-controls.md`: «no more than about five segments on iPhone»),
   а режимов уже 6 и будет больше; на 320 pt и AX3 подписи uk/ru не помещаются физически. Поэтому
   сегмент не нарисован даже как вариант.
4. **Ни одной второй двери в одну игру и ни одной новой сущности.** «Продолжить» — только день
   (он и так уходит на Today), игра режима — в строке режима; строки — тот же компонент хаба PD-144,
   чип в шапке — тот же чип Чернил. Новых цветов и токенов нет.

Цена C: хаб PD-144 переписывается (уходят список сложностей с хаба, строка «Режим» и закреплённая
«Начать» — всё это переезжает в шит); у Классики путь до новой игры становится «строка → Начать»
вместо «Начать» (последняя сложность в шите предвыбрана, так что тапов столько же или на один
больше).

## 5. Состояния по требованиям тикета

- **Ширины 320 / 390 / 430.** Переключатель Width; в кадрах 320×568 и 390×844, 430×932 — хаб.
  На 320 у A плитка ~139 pt: имена влезают, статус переносится на 2 строки.
- **Dynamic Type AX3** (40 px). A: сетка плиток → 1 колонка, «Новое» уходит из угла в поток.
  B/C: строки перестраиваются в столбец (значок → имя → описание), шеврон абсолютом справа (правило
  PD-144). Шит: прокручивается только середина (описание + сложности), «Отмена» и «Начать» —
  `flex:none`, растушёвка снизу (PD-144 §4.1–4.2). Чип в шапке партии — только значок.
- **Самые длинные строки.** uk «Ляпка-вихованець», «Заповнити кандидатами», «Незавершену сітку (…)
  буде відкинуто.»; ru «Каждая цифра окончательна: без отмены и без ластика для цифр. Неверная
  оставляет кляксу.» — самое длинное описание. В кадрах: `*-hub-many-390-light-uk-ax3`,
  `*-sheet-new-320-light-ru-ax3`, `*-sheet-liar-320-light-ru-ax3`, `C-pet-320-light-uk-ax3`.
- **Светлая/тёмная** — все ключевые состояния в обеих; токены только из v2/PD-144.
- **Reduce Transparency** — системный media query + переключатель макета: таб-бар (и hub-bar у B)
  становится непрозрачным `--glass-solid`, у контекстного меню размытие фона заменяется
  затемнением. Кадры `*-hub-one-390-dark-en-rt`.
- **Reduce Motion** — в макете нет анимаций, кроме переключателя питомца (выключается).

## 6. Тексты: описания режимов и опции (1–2 предложения)

Это **черновики для тултипа/шита**, не спецификация механик: Фонарь/Глифы/Мелодия описаны так, как
их понимает концепт; если механика изменится, текст меняется вместе с ней.

| Режим | en | uk | ru |
|---|---|---|---|
| Classic / Класика / Классика | Plain sudoku: notes, undo and hints are all there. | Звичайне судоку: нотатки, скасування й підказки на місці. | Обычное судоку: заметки, отмена и подсказки на месте. |
| Ink / Чорнило / Чернила | Every digit is final: no undo and no eraser for digits. A wrong one leaves a blot. | Кожна цифра остаточна: без скасування і без гумки для цифр. Хибна лишає ляпку. | Каждая цифра окончательна: без отмены и без ластика для цифр. Неверная оставляет кляксу. |
| Liar / Брехун / Лжец | One of the given digits is a lie. Find it, then press and hold it to accuse. | Одна з даних цифр бреше. Знайдіть її та утримуйте, щоб звинуватити. | Одна из данных цифр лжёт. Найдите её и удерживайте, чтобы обвинить. |
| Melody / Мелодія / Мелодия | Each digit you place sounds a note. A solved grid plays its own tune. | Кожна поставлена цифра звучить нотою. Розв’язана сітка грає власну мелодію. | Каждая поставленная цифра звучит нотой. Решённая сетка играет свою мелодию. |
| Lantern / Ліхтар / Фонарь | The board is dark. Only the row, column and box of the selected cell are lit. | Поле в темряві. Світяться лише рядок, стовпець і блок вибраної клітинки. | Поле в темноте. Светятся только строка, столбец и блок выбранной клетки. |
| Glyphs / Гліфи / Глифы | Nine shapes instead of digits. The same logic, without a single number. | Дев’ять фігур замість цифр. Та сама логіка — жодного числа. | Девять фигур вместо цифр. Та же логика — ни одного числа. |
| **Опция:** Blot the pet / Ляпка-вихованець / Питомец-клякса | A tiny ink blot on your result card and in Year. It reacts to how the day went and never comes onto the board. | Крихітна чорнильна ляпка на картці результату й у Році. Реагує на те, як минув день, і ніколи не виходить на поле. | Крошечная чернильная клякса на карточке результата и в Году. Реагирует на то, как прошёл день, и никогда не выходит на поле. |

Терминология: «ляпка» в uk и «клякса» в ru уже заняты Чернилами (`ink.rowBlots`, `blotSay`) —

развести с ink-«blot» (например «Inky»). «Лжец»: в концепте 05 бренд-вариант uk — «Брехун», взят он.

## 7. Что меняется против утверждённого PD-144 (если выбран C или A)

- Строка «Режим» и шит «Режим» (Классика/Чернила) **удаляются** — режим выбирается строкой списка.
- Список сложностей уезжает **с хаба в шит режима**; последняя выбранная сложность режима предвыбрана.
- Закреплённая «Начать» на хабе **удаляется** (она в шите).
- «⋯ → Новая сетка» в партии открывает **шит текущего режима** (с предупреждением), а не хаб;
  тап по выбранной вкладке Play по-прежнему возвращает на хаб без потерь.
- Шит «Отбросить эту сетку?» PD-144 не нужен как отдельный: предупреждение стоит в самом шите
  перед «Начать новую». (Если хочется второго подтверждения — ActionSheet PD-144 переиспользуется.)
- Хранилище: слот на режим (решение 1). Пустая позиция 20 px под «раздел релиза 2» больше не нужна —
  раздел и есть «Режимы».

В B меняется только: строка «Режим» → раздел «Другие режимы», «Продолжить» перечисляет все слоты.

## 8. Риски и непроверенное

- Кадры не рендерил (у дизайнера нет Bash) — скрипт сам печатает переполнения/обрезку/цели < 44 pt/
  кнопки шита за краем (`PD163.check()`). Первым смотреть: `wk-A-hub-many-320-light-uk`
  (плитки на 320), `wk-C-hub-many-390-light-uk-ax3`, `wk-*-sheet-new-320-light-ru-ax3`
  («Начать новую» и «Отмена» на экране), `wk-C-ctx-melody-320-light-uk` (меню не за краем),
  `wk-*-game-ink-320-light-ru-ax3` (чип схлопнут до значка).
- Значки режимов (маска Лжеца, фонарь, глифы, нота) — рабочие, не финальные; при утверждении
  варианта стоит отдельный короткий проход по иконографии.
- Долгое нажатие в iOS-PWA конфликтует с системным выделением/лупой — в реализации на строках
  нужны `-webkit-touch-callout:none; user-select:none`; проверить на iPhone.
- Поле в партии иллюстративное: никакой механики Фонаря/Глифов/Лжеца не нарисовано намеренно.
