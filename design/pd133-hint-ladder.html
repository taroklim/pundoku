Pundoku — hint ladder (PD-133)

Owner decision 6.1, option 2: help for a stuck player is a ladder that never gives the digit — region, technique, cells, walk-through. Taking it marks the day with help in Year. This is a mockup for approval, not an implementation. Notes, copy in en/uk/ru, the decision table and the open questions are in design/pd133-hint-ladder.md.

Frames 390×844, safe areas simulated 59 / 34, themes pinned by class. No new colour is introduced: the hint layer is ink and wax at new opacities plus four distinct shapes.

A. Entry point — the top bar, not the pad

The Notes / Undo / Erase row is already tight at 320–390 pt and ink drops to two buttons, so a fourth button is out. The hint sits in the toolbar, left of the gear: a 44×44 target in the same quiet --label-2-grouped as the gear, as far from the working thumb as the screen allows — Good Sudoku's hint button is criticised for exactly the accidental taps that distance prevents (competitors-a §2.4). Discovery is covered by a one-time inline tip in the gap, which is empty space anyway.

A hint marks the day

Pundoku never fills a cell for you. A hint walks you to the next move in four steps: where to look, which technique, which cells, and why.

  • The day is recorded as solved with help — in the year and on the card.
  • Further hints today don’t change the mark.
  • If Pundoku finds nothing to explain, nothing is marked.

A3 light. One-time rule sheet, the same pattern as the ink rule (PD-74) — shown once per device, ever, before the first hint of all time. After that the honest line lives in the dock footer, so it is never a surprise. Re-readable in Settings → How Pundoku works.

B. The four rungs — a dock in the pad’s place, never over the board

The hint must point at the board, so it cannot be a sheet. The dock takes the pad’s place (the pad is inert while you are reading anyway) and grows only into the gap, which is 135 px tall at default type — the board does not move. No third sheet layer, no stack (heuristic H-17). One button goes down the ladder, one closes. Closing at rung 3 or later leaves the selection on the hint cell, so the pad comes back with the right cell already chosen — a cell, never a digit.

C. Two branches that are not a ladder

E. Ink mode — no hints at all

Ink is a bargain: every digit is final, there is no undo, no digit eraser, and a wrong digit seals the cell and fills the right digit for you. A hint is a retreat from that bargain, and the mistake branch is meaningless there because a mistake cannot survive on the board. So the bulb is absent, not dimmed — the same choice PD-74 made for Undo. One line is added to the rule sheet.

Ink doesn’t lift

In ink mode every digit you place is final. Read this before you start — you can’t switch later.

  • No undo, and no eraser for digits.
  • A wrong digit leaves a blot: the cell seals, and the right digit is filled in for you.
  • Notes stay — pencil still lifts.
  • No hints, either.

F. The four marks, enlarged

Each mark is a different shape, so none of them depends on colour, and none of them collides with the three marks the board already uses: the indigo selection ring (solid, 2 px, on the border), the wax error ring (2–3 px, on the border) and “same digit” (10 % wash, no outline).
