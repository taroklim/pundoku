### 2.3 Настройка «Highlight wrong digits» (PD-112)

- **Дефолт выкл**: чистый профиль (LS пуст) — выкл (WebKit, en/uk/ru). Профиль со «старым состоянием» — выкл: (а) сохранён `storageState` с IndexedDB (партия с неверной цифрой) без ключа `pundoku.highlightWrong` в новом контексте — цифра не подсвечена; (б) только язык в LS — switch выкл. Включает лишь значение «1».
- **Переключатель в Settings**: секция «Game/Гра/Игра» между «Language» и «Recovery key»; `<input type=checkbox role=switch>` (aria-checked как атрибута нет — состояние отдаёт нативный checkbox; `getByRole('switch',{name,checked})` находит и по имени, и по состоянию); `aria-describedby` → футер; визуально 51×31; клик по любой части строки-label переключает (тап WebKit), строка 53 px высотой (≥44).
- Клавиатура (Chromium): Tab доходит до switch за 3 нажатия, `:focus-visible`, outline 2 px цвета ink; Space включает/выключает, пишет/удаляет `pundoku.highlightWrong`; Enter не переключает (норма для switch).
- Подпись и футер на трёх языках — тексты соответствуют `en/uk/ru.json`, секция/метка/футер переводятся (shots `set-en-390-light-off/on`, `set-ru-390-light-off`, `set-uk-320-dark-off`).
- Раскладка: 320/390/430 × en/uk/ru — горизонтального скролла нет, switch у правого края (16 px), метка не обрезана. База шрифта 17 px (как iPhone): строка 53 px; на 320 для uk/ru метка в 2 строки, строка 66 px. AX3-приближение (40 px): 320 — строка 178–230 px, метка в 3–4 строки, ничего не обрезано (см. находку F5).
- Состояния switch: forced-colors (светлая/тёмная) — рамка ButtonText, вкл — Highlight, бегунок HighlightText; contrast more — обводка `rgb(60,60,67)`; тёмная тема OK (shot `set-cr-forced-on`, `set-cr-focus`).
- **Выкл, обычный режим (Today и Play, WebKit, светлая и тёмная)**: неверная цифра имеет цвет ink (как верная), `.cell` без `err`, `.d` без `err`, `.ring` без `err`, `::after` рамки нет, aria-label «Row R, column C, your D» без «wrong», в live-регионах (`role=status`) нет слова wrong/error (только «N cells left» по вехам). Подсчёт `.err` в документе = 0. Клавиатурный ввод неверной цифры — то же самое.
- **Вкл**: цвет сургуч, `cell err`, кольцо `ring err`, рамка 2 px, aria «…, wrong» (светлая `rgb(179,38,30)`, тёмная `rgb(255,107,94)`).
- **Живое переключение без reload**: (а) в SPA Today → шестерёнка → Settings → switch → Back: маркер `window.__marker` сохранился (перезагрузки не было), подсветка появилась; (б) настоящее переключение на второй вкладке того же контекста (событие `storage`) меняет открытое поле Today и Play без reload в обе стороны, включая кольцо и aria; (в) в архивном дне — синтетическое storage-событие, работает.
- **Перезагрузка**: вкл переживает reload, выкл (ключ удалён) переживает reload; сохранённая партия с неверной цифрой подсвечивается/не подсвечивается по текущему значению.
- Запасное хранилище: при `localStorage`, бросающем исключение (приватный режим), приложение не падает, switch работает до перезагрузки, поле реагирует.
- Светлая/тёмная — OK (shots `today-wrong-off/on-light`, `play-wrong-off/on-dark`).

## 4. Что не проверено

- Реальный iPhone/iOS Safari/PWA: VoiceOver (озвучка switch, подписи ячейки с/без «wrong», футер как описание), системный Dynamic Type, нативная отрисовка `role=switch`, тап по строке пальцем, рендер иконки на реальном OLED. Предлагаю владельцу при следующем iOS-чек-листе: Settings → Game → включить/выключить, поставить неверную цифру, проверить цвет и VoiceOver; шестерёнка в тулбаре Today.
- Windows High Contrast на реальной ОС (проверен только эмулятор forced-colors Chromium; его цвета Highlight в эмуляции не равны реальным).
- Цветовая слепота — по ТЗ не обязательна.
- Синхронизация настройки между устройствами не проверялась (по замыслу настройка локальна, в снапшот не входит).
- Реальная вторая вкладка/окно PWA на iOS (событие `storage` проверено между страницами одного контекста Playwright).
