# Pundoku

Чистое судоку как ежедневный ритуал. Один игрок, никакого мультиплеера, никакой игровой обёртки
(персонажи/XP/пиксель-арт — отвергнуто владельцем явно). Название обыгрывает «Pun», никнейм игрока.

**Источник контекста и решений владельца — `reports/sudoku-pwa-research/07-concept-draft.md`**
(корень портфеля). Читать первым: рамка, принятые/отвергнутые идеи, визуальное направление v2 с
токенами, состав релизов, решения владельца. Отчёты ресёрча 01–06 там же (рынок, механики, техника
PWA/iOS, концепции, источник ежедневной сетки).

## Назначение продукта
PWA для iPhone: сетка дня (общая для всех, из Sudoku.com через свой прокси с фолбэком на
собственный генератор), свободная игра по сложностям, карточка результата с аналитикой
собственного пути решения (тепловая карта, применённые техники, spoiler-free шаринг),
**постоянная бесконечная сетка** (идея владельца: последняя поставленная клетка ежедневной сетки
открывает подсказку в личной пустой сетке со скрытым решением), Year-полотно (год как рисунок,
цвет по качеству). Позже: Чернильный режим (без отмены, ошибка = клякса), Таймлапс прохождения,
Лжец (одна ложная подсказка), Мелодия сетки, Питомец-клякса, Фонарь/Глифы.

## Целевая аудитория
На старте — владелец (iPhone 16, iOS PWA). Публичный релиз не планируется до появления
решения владельца; языки en (default) / uk / ru закладываются сразу.

## Роадмап
- **Релиз 1 (утверждён 2026-09-29):** движок (генератор + решатель с логом техник: naked/hidden
  single, locked candidates, pairs + лог ходов с таймингами); Play (9×9, 4 сложности, заметки,
  undo, подсветка, таймер); Today (прокси Sudoku.com `GET /api/v2/dc/YYYY-MM-DD` c заголовком
  `X-Requested-With: XMLHttpRequest`, фолбэк на генератор с seed = дата); карточка дня
  (тепловая карта пути, время/чисто/техника, win_rate, PNG-шаринг без цифр); постоянная сетка на
  Today; Year-полотно; PWA (офлайн, установка), i18n en/uk/ru, системная тёмная тема,
  reduced motion/transparency; **аккаунт и синхронизация** (см. ниже).
- **Аккаунт (уточнение владельца 2026-09-29):** всё персональное — постоянная сетка, Year-полотно,
  статистика, карточки дней — обязано пережить потерю/чистку устройства (iOS может стереть
  IndexedDB, отчёт 03 §1). Решение Coordinator'а для релиза 1: **анонимный аккаунт устройства,
  создаётся сам при первом запуске, без экрана регистрации** (HIG `onboarding.md`: откладывать
  вход), сервер хранит снапшот прогресса и является источником правды для постоянной сетки и
  года; **привязка e-mail/пароля** (чтобы восстановить на новом телефоне или зайти с двух
  устройств) — отдельный тикет, включить в релиз 1 как последний шаг, UI — в настройках, не при
  запуске. Если владелец захочет полноценную регистрацию при первом входе — это его решение,
  спросить перед реализацией привязки.
- **Релиз 1.1:** Чернильный режим, Таймлапс (просмотр в приложении, экспорт PNG отпечатка).
- **Релиз 2:** Лжец (критерий честности — в генераторе с самого начала, см. отчёт 05 §3),
  Мелодия сетки, Питомец-клякса (только карточка/Year, никогда на поле), Фонарь/Глифы.
- **НЕ делать:** ритм недели, виджеты/Watch, вибрации, мультиплеер, любая геймификация из SUMMON.

## Порядок первого шага (решение владельца 2026-09-29)
Визуал v2 **не утверждён вслепую** — первый тикет: **HTML-макет экрана Today** по токенам и
структуре из `07-concept-draft.md` § «Визуальное направление v2» (показать оба варианта таб-бара:
3 вкладки Today·Play·Year и 4 с отдельной Grid), на утверждение владельцу до любого UI-кода.
Цвет чернил — решить по макету/иконке, рабочий #3B48B0. Движок и прокси от макета не зависят —
идут параллельно.

## Архитектурные ограничения
- Стек по аналогии с портфелем: React + TypeScript + Vite, Node/TS бэкенд (минимальный: прокси
  Sudoku.com + бэкап прогресса), Postgres, Docker. Офлайн-first: генерация и прогресс на клиенте
  (IndexedDB), сервер — не источник правды для игры.
- Лицензии: движок на MIT-основе (`sudoku-core`/собственный код); GPL-код (HoDoKu, Sudoku
  Explainer) **не копировать** — только переписывать логику техник по описанию.
- iOS PWA: `100dvh`, `viewport-fit=cover` + `env(safe-area-inset-*)`, `touch-action: manipulation`,
  подавление double-tap zoom, шрифты ≥16px в нативных input, звук только после жеста.
  Полный список — `reports/sudoku-pwa-research/03-tech.md`.
- Дизайн: HIG через скилл `apple-design` (`.claude/skills/apple-design`) — дизайнер и QA
  используют его как ревьюера; шрифты только через CSS-генерики (`ui-serif` → New York для данных
  подсказок, `system-ui` → SF Pro для цифр игрока), ничего не встраивать. Контраст в токенах
  посчитан — не понижать. Стекло только на таб-баре с фолбэком на непрозрачную заливку.
- Sudoku.com — чужой контент, ToS Easybrain; всегда через адаптер с фолбэком, никогда напрямую из
  браузера (CORS нет).

## Конвенции разработки
- Тикеты `PD-<n>` в `STATUS.md`; каждый тикет — живой QA до закрытия (Playwright + реальная
  сборка), не статическое ревью.
- Developer-агенты в изолированном worktree обязаны закоммитить результат в ветку или
  скопировать в основную копию до удаления worktree (инцидент GR-378).
- QA поднимает dev-стенд только в изолированном worktree/clone, не в основном чекауте.
- Важные базовые визуальные решения (макет экрана, иконка, палитра) — на согласование владельцу
  заранее, не после реализации.
- iOS-проверки агенты выполнить не могут — просить владельца, формулируя конкретные шаги.
